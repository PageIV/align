# align-ledger：手动打开账本面板

用户主动叫这个技能，意思就是：**现在把账本面板打开**。

## 做什么

立刻调 `align_open_ledger`，`root` 传当前工作区的绝对路径。然后一句话说完（"账本已打开，N 条生效"），不要再展开别的。

## 边界

- **不要先调 `align_list` 再把内容念一遍。** 用户要的是那个界面，不是一段转述。
- **不要弹落地表单。** 表单是 `align-now` 的活；这个技能只管看和改已经落下的条目。
- 面板里能做的三件事（改标签、取代、退休）都直接写 `ALIGNMENT.md`，你不用在旁边代劳；用户如果想让你改，他会直说"把 C-0NN 改成…"。
