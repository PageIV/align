# align-now：手动调出落地表单

用户主动叫这个技能，意思就是：**现在给我那张表单**。别的动作都是多余的。

不要走侧聊、不要重新展开追问、不要反问"你想落地哪几条"——那正是他不想再做的事。这个技能存在的理由就是：让"调出表单"这件事不依赖模型自己想起来。

## 做什么

1. 从**最近一轮**里挑出该由用户决定的断言，1–5 条，每条一句话。取内容的顺序：用户选中的文字 → 他这一句里点到的东西 → 上一条回答里的结论。
2. 每条给一个建议目的地与一个标签。规则与 `align` 技能相同：目的地是 `land` / `restate` / `ignore`，标签只是标签（概念对齐 / 错误纠正 / 方向纠偏 / 细节填充）。
   - 如果这一轮是在**改一条已有的已确认项**（用户说"那条不对了/过时了，应该是 X"），把 X 作为候选、填上 `supersedes: "C-0NN"`。旧条目会在用户确认后退休，不再每轮注入；不填就是新增一条，两条会并存。
3. 立刻调 `align_land`，`root` 传当前工作区的绝对路径（MCP server 的工作目录是插件目录，不是用户的项目）。
4. 表单关掉之后**一句话**收尾，只说结果：
   - 写进账本的 →「已落地 C-019」（有编号就带上），可以补半句"从下一轮起每轮带上"。
   - 复述的 →「已复述，会在你下次提问时到达，只带一次。」
   - 有需要你**当场原样说出来**的复述 → 把那段原样说出来，加粗或引用，别改写；这一条不能只报"已复述"。
   - **不许提**文件名、路径、session id、工具名、字段名（`inline` / `inboxed` 这类），也别把工具结果的结构复述一遍。用户不需要知道这些。

## 边界

- 候选里只放**你真心觉得该由用户决定**的。凑数会让他每次都得多点几个 Ignore，下次就不叫这个技能了。
- **不必先开侧聊。** 侧聊是用来追问的；这个技能只负责把已经说清的东西落下来——主线程里刚说过的话一样能落。
- 你拿不准的别编进候选。表单不是让你向用户提问的地方。
- 用户按了 skip、或者一条都没选中：什么都不写，一句话带过。
