# ADR-0001：Codex 优先，核心逻辑宿主无关

- 状态：已接受
- 日期：2026-10-04

## 背景

"为 Agent（例如 Codex）设计插件"里的"例如"意味着宿主不止一个。但各宿主的能力差异极大：Codex 有 plugin/marketplace 清单、skill、自带 MCP server、能在当前任务的侧边面板里渲染 MCP Apps；其他宿主未必有线程级工具，也未必有可用的 UI 通道。

## 决定

v1 只做 Codex 插件，不做宿主抽象层。但把**确认项存储、类型策略、supersede 链、账本读写**实现为独立的纯逻辑模块，不依赖任何 Codex API；Codex 相关的部分（清单、skill、MCP 工具、面板）只做薄封装。

## 后果

- 第一版能吃到 Codex 的全部能力：侧边面板、MCP 工具、插件钩子。（原文还列了"被自动读取的 `AGENTS.md`"——它只在 app 重启时读一次，不能每轮生效，已退役，见 ADR-0002。）
- 换宿主时只需重写薄封装层，逻辑层可以原样搬过去。
- 代价：v1 不能宣称"多宿主支持"；逻辑层与封装层的边界需要人工守住，否则会慢慢渗漏。
