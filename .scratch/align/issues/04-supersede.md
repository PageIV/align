# 04 — supersede 与冲突

Status: open
Blocked by: 02
Type: task

## 目标

确认项会演化。旧的不能删——"我们曾以为是 X、后来改成 Y"这段历史本身就是对齐价值。

## 交付

- 追加式更新：新条目**取代**旧条目时，旧条目状态写成 `superseded by C-0NN`，移入 `ALIGNMENT.md` 的"已失效"区，保留完整链
- 热块只显示 active 条目
- 面板提供"取代 #N"的操作，并在检测到同一主题时给出提示
- 层级优先级：线程层条目与项目层条目冲突时，**线程层优先**，但只标注、不阻塞

## 验收标准

1. C-014 取代 C-009 后：热块里只剩 C-014；`ALIGNMENT.md` 里两条都在，C-009 的状态是 `superseded by C-014`。
2. 重复执行同一次取代不产生第二条失效记录（幂等）。
3. 线程层与项目层冲突时，主 Agent 的表现以前者为准，且不需要用户处理任何弹窗。
