# 18 — 落地表单：主次与可编辑内容

Status: 待真机复验
Blocked by: 14
Type: task

## 现象（2026-10-07 真机）

用户在侧聊里看到表单后报三条：

1. **主次不清**——顶部一大段图例（`Align = … / Restate = … / Ignore = …`），条目本身反而淹没在里面，多条候选时尤其分不清哪句对应哪条。
2. **名词解释不该常驻**——最好是鼠标指到标签上再显示。
3. **要复述的内容看不见**——那段话只作为字段标题出现，用户不知道真正被带回去的是不是这个，也没法改。

## 查到宿主能做什么

读 `app.asar` 里的 elicitation 面板：

- 选项被收敛成 `{const, title}` 两个键（`gXn`）——**没有位置放 hover 说明**。第 2 条只能落成"解释并进选项文字"。
- 但 `enum` 支持 `enumNames`（每项一个显示名），所以选项可以写成「Restate · 只带回主线说一次」。
- **文本字段吃 `default`**（`vXn` 只跳选择型字段）。所以第 3 条能做：内容预填在一个可编辑框里。

## 交付

- 表单形状搬进 `logic/landing-form.mjs`（可测）：一条候选两个字段——`t<N>` 内容框（可改，预填 statement）、`c<N>` 去哪（三个选项，文字带解释）
- 顶部 message 收到两行：不再有图例
- 三个目的地的 `hint` 改成短句，新增 `destinationChoice(slug)` → 「标签 · 解释」
- `destinationSlug` 容错：认出「Restate · 只带回主线说一次」这种整句（认不出来的代价是静默落成 Ignore）
- 提交时用**用户改过的那句**（内容框的值）落地或复述

## 验收标准

1. 真机：表单顶部只有两行说明，没有 `Align = …` 那一串图例。
2. 真机：三条选项各自的文字里带解释。
3. 真机：内容框预填着模型写的那句话，能改。
4. 改过内容再选 Align，账本里落的是改后的句子；选 Restate，带回去的是改后的句子。
5. `npm test` 覆盖：字段顺序、`enum`/`enumNames` 逐项对齐、顶部无图例、建议位置、整句标签能认回来。
