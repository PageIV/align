# 06 — 提升到项目层

Status: wontfix
Blocked by: 03, 04, 05
Type: task

## 目标

把一条只活在当前对话里的确认项，升级成每轮自动生效的项目层条目。这是线程层脆弱性的唯一出口，必须在面板上随手可得。

## 交付

- 面板按钮 + `align_promote(ids)`
- 提升 = 写进 `ALIGNMENT.md`（来源记成"来自哪一轮、原本是哪条线程层条目"）+ 更新热块
- 提升后线程层不再需要重复注入

## 验收标准

1. 线程层条目提升后，热块里出现它；`ALIGNMENT.md` 的"来源"字段能看出它原来来自线程层。
2. 提升后开一条新线程，主 Agent 能说出这条确认项——这是成功标准里最硬的一条。
3. 提升操作幂等。

## 上下文指针

- `.scratch/align/spec.md` 的"成功标准"第 1 条
- `GLOSSARY.md`：作用域

## 结论（2026-10-05）

不做了。它依赖的 05（线程层落地）已作废，提升这个动作没有对象了——现在只有项目层一个作用域，"提升"从词汇表里移除。线程作用域将来若真的回来，再重新想它的入口。
