# 15 — 三个目的地：写入 / 复述 / 不写入，类型退化成标签

Status: resolved
Blocked by: 14（落地已经被 elicitation 接管）
Type: task

## 背景

命令式断言（C-007 那种"统一走 `align_land`"）落进账本后每轮注入，等于每轮重复一道命令。风险与讨论见 [docs/discussion.md](../../../docs/discussion.md) 2026-10-05 那条。结论是给它换个目的地，而不是靠模型猜。

## 要做的

**表单只让人选去哪，不让人选分类**（2026-10-06 改成两项：不落地去掉，因为表单自带 skip 按钮；其余两项在表单上显示英文）：

| 选项 | 去哪 | 活多久 |
| --- | --- | --- |
| Align（落地） | `ALIGNMENT.md` → 热块 | 每轮注入，直到退休 |
| Restate（复述） | 收件箱 | 下一次**不属于当前会话**的提问注入一次，随即消费 |

一条都不想留时按表单自带的 skip——那是整张表单不提交，不是逐条跳过。所以候选里不该有"不值得留"的东西；逐条丢弃的粒度没有了（SKILL.md 已写明）。这也意味着**提交表单就等于接受每条的建议**：没填的字段按建议处理。

**默认停在模型建议上。** `CANDIDATE_SCHEMA` 增加一个建议目的地字段，由调用 `align_land` 的那个 Agent 顺手填——它本来就在把侧聊结论压成候选断言。零额外模型调用。表单默认值取这个建议。

**类型退化成标签。** 用户不再选类型之后，类型唯一的行为效果（`restate` 策略）就没有了：`logic/config.mjs` 里的 `typePolicy` 与 `[types.*] restate` 一并删掉，类型只剩"给人看的标签"。热块行首的前缀保留——标错只影响展示，不影响行为。

**收件箱。** 条目记下写入时的 `session_id`；钩子在下一条**不属于该会话**的提问上投递它，投递即消费。主线程里落的"复述"不走收件箱——工具结果直接让当前这轮把它说出来。

**收件箱必须放在项目里**（`.align/inbox.md` 这类），不能放进 `PLUGIN_DATA`。同一个 app 里可以同时开着两个项目，放项目里才天然隔离；放插件数据目录会让 A 项目的"复述"被 B 项目吃掉。

**"新开一个侧聊会不会把条目吃掉"——已验，判据是 `transcript_path`。**（2026-10-05，版本 0.2.2 探针）

原先"投递给下一条不属于写入者的提问"挡不住新侧聊：新侧聊的 `session_id` 与写入者不同，会直接把条目认领走。宿主这边也查不到"这条会话是不是侧聊"——侧聊根本不落库（`state_5.sqlite` 的 `threads` 表、`thread_spawn_edges`、`~/.codex/sessions/` 里都没有它）。

但钩子输入里有一个现成的判据：

```
主线程  transcript=/Users/page/.codex/sessions/…/rollout-…-01a10a1a-….jsonl
侧聊    transcript=null
```

侧聊是临时的，没有 rollout 文件，所以 `transcript_path` 为 `null`。（`agent_type` / `agent_id` 两边都没有，指望不上。）

**最终投递规则**：条目记下写入时的 `session_id`；钩子只在**`transcript_path` 非空、且 `session_id` 不等于写入者**的会话里投递它，投递即消费。新侧聊 `transcript` 是 null，不会认领；跨项目由"收件箱放在项目里"隔开。

一个待观察的边角：全新的线程在**第一条**消息时 rollout 可能还没建立，`transcript_path` 也许为 null——那样首条消息不会投递，第二条才送到。真出现再处理。

## 验收标准

1. 表单每条三个选项；每条的第一项是模型给的建议，条目描述里写明「建议 X」。（~~默认停在建议上~~ —— 宿主不预选选择型字段，做不到，见 Comments 2026-10-06 那条；改成"空值按建议处理"。）
2. 删掉 `.align/config.toml` 里的 `[types.*] restate` 后行为不变（除了不再有类型策略这回事）。
3. 侧聊里选"复述" → 在侧聊里再发一条**不消费它** → 回主线程发一条，内容出现一次，随后消失。
4. 主线程里选"复述" → 当轮回复里说出来，不写账本、不写收件箱。
5. 账本条目仍带类型标签，热块行首前缀不变。

## 已知缺口

条目若一直没人去"别处"提问，会一直躺着。需要过期策略（比如超过若干小时标为过期），先不做，但要记着。
