# 08 — 面板成形

Status: open
Blocked by: 03, 04, 05
Type: task

## 目标

把 02 那个"一个输入框"的占位面板做成真正能用的界面。面板是"给我一个选择"这个产品核心的物理形态，做差了整个插件就没了意义。

## 交付

- 多条候选断言的勾选（默认全不勾，只勾你认可的）
- 每条可改类型；作用域选择（默认线程层）
- 冲突提示（检测到同主题已有条目时提示可"取代"）
- 承重提示：静默类型 + 线程层 = 脆弱，旁边给出"提升到项目层"
- 在 ~371px 宽度下可用；纯内联 CSS/JS，不引任何外部资源

## 验收标准

1. 面板在侧边栏 371px 宽下无横向滚动、无截断。
2. 一次可以勾多条、逐条改类型、一次落地。
3. 所有资源内联；断网也能用。
4. 面板上的文案与 `GLOSSARY.md` 的说法一致，不出现"记忆""事实""上下文注入"这些被禁用的词。
